🛍️ Virtual Shopping

📅 Year Created: 2025

An interactive shopping simulator where users set their balance, add items to a cart, and see real-time price updates using JavaScript.

🚀 Live Demo 💻 GitHub

📌 What It Does

Simulates an online shopping experience as an pop-up alert function where user could enter their balance amount, add items to the car, and see their balance decrease after every purchase.

👨‍💻 My Role

Designing all the components that is within the alert function. With creating all the math and javascript code so the balance the user enter decrease. Being the coder, problem solver, and designer.

⚙️ Technologies Used

This project was built using core front-end web technologies. HTML was used to create the pop-up alert functions and JavaScript was used to handle all interactive logic such as balance updates, cart calculations, and dynamic user interactions.
